# Product Detail Page v2.4

범용 상품 상세페이지 제작용 커스텀 스킬입니다.

대상:
- 속옷 / 내의
- 잠옷 / 홈웨어
- 일반 의류

핵심 흐름:
Ask Your Question → VOC → Real Why → 상품군 분기 → 페이지 구조 → 후킹 → 본문 카피 → 이미지/레이아웃 → CRO-lite → 표현 검수

## 추천 사용법

처음에는 실제 상품 1개로 테스트하세요.
테스트 후 아래를 기록하면 v1.2 개선에 도움이 됩니다.

- 질문이 너무 많거나 부족했는지
- 페이지 구조가 실제 제작 흐름과 맞았는지
- 3안이 정말 다른 각도였는지
- 카피가 길거나 반복되었는지
- 이미지 지시가 제품 원본을 충분히 보호했는지
- 빠진 상품군 전용 규칙이 있었는지


## v1.1.1 update
- 전체 상세페이지 출력 밀도 축소
- 근거 상태/내부 분석 기본 비노출
- 섹션별 고정 표 포맷 적용
- 레이아웃/역할/이미지 고정규칙 자동 출력 제거
- CRO-lite 및 표현 검수 압축


## v1.1.2 update
- 전체 상세페이지의 마지막 `PRODUCT INFO` 섹션 기본 유지
- 존재하지 않거나 미확인인 실측표·후기·인증자료를 필수 이미지로 요구하지 않도록 보강
- 자료가 없을 때는 확인된 정보로 대체 가능한 이미지 제안
- 자료 없음 경고의 반복 출력 최소화


## v1.1.3 update
- 사용자가 직접 확인한 촉감·두께·유연함·늘어남·핏·착용감을 `확인된 상품 특성`으로 활용
- 소재 섹션을 혼용률 고지에서 끝내지 않고, 확인된 실제 사용감과 구매 장점으로 연결
- 섬유 혼용률만으로 신축성·통기성·흡습성 등을 자동 추론하지 않도록 구분
- 주관적 착용 특성과 시험/인증이 필요한 객관적 기능성 클레임을 분리
- 실제 스판 혼용이 없을 때 `스판 함유` 표현 금지, 실제 늘어남이 확인되면 관찰 기반 표현 허용


## v1.1.4 update
- 사용자 확인 특성을 적극 활용하되 그 때문에 섹션 수와 설명량이 늘어나지 않도록 압축 규칙 강화
- 전체 상세페이지 기본 6~8개 섹션, 9개 이내 우선 원칙 추가
- 10개 이상일 경우 자동 병합 검토 규칙 추가
- `MATERIAL + COMFORT`, `WAIST + LEG FINISH + INNER DETAIL`, `COLOR + SET` 등 유사 섹션 병합 기준 추가
- 작은 디테일마다 독립 섹션을 만들지 않고 `DETAIL` 등으로 묶도록 보강
- 전체 설계도 4열, 후킹 3열, 섹션별 제작안 4행 표 형식 고정
- 전체 상세페이지 기획에서 `CRO-lite`와 `표현 검수`를 반드시 유지하도록 강제
- 마지막 종합 해설/흐름 재요약 및 과도한 10개 이상 분절 구조 기본 출력 금지


## v1.1.5 update
- `매일/데일리/편안함/부담 없이/깔끔하게` 등 범용 카피의 반복 제한 규칙 추가
- 동일 단어뿐 아니라 의미가 같은 재진술도 중복으로 판단하는 `카피 중복 패스` 추가
- SET / DESIGN / FABRIC & COMFORT / TYPE / DETAIL / SIZE / PRODUCT INFO가 서로 다른 구매 질문을 담당하도록 포인트 분리
- 새로운 정보가 없는 INTRO·WHY·DESIGN VIEW 등은 삭제 또는 병합
- 동일 핵심 단어는 제목·핵심카피 기준 2회 이내를 우선하도록 보강
- 정보가 적은 상품은 문장을 억지로 늘리지 않고 짧고 밀도 높은 상세페이지를 우선


## v1.1.6 update
- `의미가 같으면 중복` 같은 강한 금지 규칙 제거
- 카피 반복을 `AUTO / DIVERSE / BALANCED / FOCUSED` 방식으로 유연하게 운용 가능
- 소구점이 적은 상품은 같은 핵심 장점을 초반·중간·후반에서 다른 표현·상황·근거로 반복 허용
- `매일/데일리/편안함` 등 범용어의 횟수 제한 제거, 근접한 연속 반복만 조정
- 각 섹션이 반드시 서로 다른 구매포인트를 가져야 한다는 강제 규칙 제거
- 6~8개 섹션은 권장 범위로 완화하고, 이미지·감성 전환·제품 확인 역할이 있으면 더 많은 섹션도 허용
- MATERIAL/COMFORT, DETAIL 등의 병합은 강제가 아니라 선택 기준으로 변경
- INTRO/WHY/DESIGN VIEW도 새 이미지 역할·리듬·확인 기능이 있으면 유지 가능


## v1.1.7 update
- 면·모달·인견 등 선호 소재가 고함량일 때 혼용률 자체를 핵심 구매포인트로 우선 강조
- 100%가 아닌 면 고함량 상품에 `순면` 표현을 쓰지 않도록 명확화
- `이런 분께 추천드려요`를 전체 상세페이지 기본 모듈로 추가하고 기능성/문제해결형은 상단 배치 우선
- 핵심 포인트 이후 `추천 대상 → 컬러/디자인 확인 → 디테일컷` 흐름을 기본 후보로 추가
- 상단에서 설명한 디테일도 다른 컬러·확대·제품 확인 목적이면 설명 없이 재노출 허용
- 진한색 상품의 단독세탁/건조기 주의 재강조 규칙 추가(케어라벨/브랜드 기준 우선)
- 하단 정보 순서를 `실측 → 제품정보 → 세탁정보 → 배송정보`로 기본 고정
- 회사 공통 하단 인포가 이미 있으면 새로 설계하지 않고 연결만 표시하도록 보강
- CRO 중복 검수를 횟수 기준이 아니라 근접한 무의미 반복 기준으로 완화


## v1.1.8 update
- 전체 상세페이지 첫 설계 시 하단 공통 인포 유무를 구체적인 체크리스트로 확인
- 실측/CONDITIONS/PRODUCT INFO/NOTICE/WASHING/배송/교환·반품/고객센터/A/S 등 실제 하단 모듈을 명시
- 초보 사용자가 무엇이 필요한지 몰라도 `없음/모름`으로 답하면 필요한 기본 모듈을 스킬이 설계
- 일부 공통 인포만 준비된 경우 `있는 것은 연결 / 없는 필수 항목만 설계`하도록 보강
- 회사별 명칭 차이를 허용하고 역할이 같은 하단 모듈은 동일 범주로 처리


## v1.1.9 update
- 상품군 제한 없이 사용할 수 있는 선택 입력값 `우선 강조 소구점 / 핵심 기능 / 문제해결 포인트` 추가
- 우선 소구점이 있으면 HOOK·핵심 포인트·추천 대상에서 우선 배치하고, 없으면 질문을 강제하지 않고 패스
- 일반 봉제형 여성 팬티에 한해 반복 입력 기본값 추가: 허리 밴드형 / 다리둘레 박음질 마감 / 안쪽 이중 덧댐 처리
- 누디·노라인·심리스·무봉제·레이저컷 또는 실제 제품 정보가 다르면 팬티 기본값 자동 해제
- 사용자 제공 정보와 실제 사진이 기본값보다 항상 우선
- 다른 상품군의 기본값은 임의 생성하지 않고 실제 작업에서 반복 검증될 때만 확장

## v2.4 update
- v2.0의 경량 모듈형 구조를 폐기하고, v1.1.9의 상세 판단·카피·CRO·이미지 규칙을 기준본으로 복원
- 전체 상세 최초 설계 시 `우선 강조 소구점 / 실제 제품 특장점 / 하단 공통 인포` 3가지 입력 확인 체계 강화
- 메인카피를 1~2줄의 짧고 직접적인 문장으로 우선 설계하고, 강한 소재·기능·숫자 소구를 범용 감성문구보다 먼저 사용
- `부드럽게, 편안하게` 같은 AI식 쉼표 병렬 카피의 습관적 사용 억제
- `이런 분께 추천드려요`를 전체 상세의 필수 모듈로 강화하고 기능성/문제해결형은 상단 배치
- 컬러별 바닥컷/정면컷이 있으면 COLOR/DESIGN VIEW를 DETAIL보다 앞에 배치
- FIT/SHAPE/TYPE 섹션을 템플릿 채우기용으로 자동 생성하지 않도록 제한
- 속옷을 성인/주니어보다 제품 구조 기준으로 분류: 하의형 / 상의형 / 브라형 / 기능 오버레이
- 주니어·성인 드로즈는 같은 하의형 구조 규칙을 사용하고 사이즈 체계만 분리
- 하의형 드로즈 실측 예시 `허리단면 / 총길이 / 밑단면`, 여성팬티 `허리단면 / 힙단면 / 총장`, 상의형 `가슴단면 / 총장 / 밑단단면` 등 추가
- 권장체중은 기본적으로 지양하고, 실제 신체사이즈 참고표가 있을 때만 공식 기준 활용
- 요실금/흡수 등 기능성 속옷은 기본 제품 구조 + 기능 오버레이 방식으로 처리하고, 패드 설명 후 `안쪽 구조` 중복 섹션 생성 방지
- PRODUCT INFO와 하단 인포에서 품질보증기준 / A/S 안내 / A/S 전화번호 누락 여부를 확인
- 회사 공통 하단 템플릿이 있으면 새로 만들지 않고 연결, 없으면 필요한 기본 모듈을 설계


## v2.4 핵심 수정
- 필수 질문이 남아 있으면 설계안 출력 금지: Ask Your Question만 출력하고 STOP
- 하단 공통 인포 상태 미확인 시 전체 설계 전 반드시 확인
- 프로젝트/과거 대화의 브랜드명 자동 노출 방지
- 일반 속옷 디테일(WAIST/FRONT/HEM/PRODUCT VIEW) 기본 통합
- 컬러/바닥컷을 DETAIL보다 앞에 배치
- PRODUCT INFO에서 품질보증기준/A/S 안내/A/S 전화번호 누락 체크 강화


## v2.4 핵심 수정
- 전체 상세 최초 요청을 MODE A(INTAKE) / MODE B(DESIGN)로 완전히 분리
- 필수 질문이 있으면 임시 구조·뼈대·목차·카피를 먼저 보여주는 동작 금지
- Q1 상품 기본정보 / Q2 우선 소구+실제 특장점 / Q3 하단 공통 인포를 최대 3개 그룹으로 확인
- 사진만으로 추정한 판매 구성·소재·사이즈·정확한 컬러명은 확인 정보로 취급하지 않음
- Ask Your Question을 상세 구조 뒤에 붙이는 방식 금지
- DESIGN MODE에 들어가기 직전 INTAKE GATE 재검사
